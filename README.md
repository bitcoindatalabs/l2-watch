# L2 Watch (Bitcoin L2 / Sidechain Audit Dashboard)

A web-based dashboard visualizing the state and flow of Bitcoin across its various Layer 2 networks and sidechains. Hosted on GitHub Pages for Bitcoin Data Labs.

## Structure
- `data/` - Contains the summarized raw data (JSON/CSV) generated by our auditing scripts.
- `docs/` - The frontend application served by GitHub Pages.
- `scripts/` - Utilities for extracting, summarizing, and syncing data from local backend nodes (e.g. `liquid-audit`) into this repository.

## Adding a New Sidechain
Each sidechain should have its own subdirectory within `data/` and its own data generation pipeline documented in `scripts/`.
